# 乘法口诀冒险美术风格

## 1. 视觉方向

**主题：明亮的数学游乐园。**

把九九乘法表做成孩子可以探索的游乐场：算式是任务卡，答案是可以收集的星星或能量球，答题过程像完成轻松的小挑战。整体活泼、亲切、清楚，避免幼儿园化或过度装饰，让二年级学生觉得有趣，也让家长觉得舒服可信。

关键词：

- 明亮、有活力、友善
- 大块留白、重点突出
- 轻松冒险感，不营造考试压力
- 图形可爱但简洁，不遮挡数字

## 1.1 手机竖屏优先

- 以手机竖屏作为主画布，先按窄屏规划信息层级，再扩展到平板和桌面。
- 题目页采用单列纵向构图：顶部放计时与进度，中段突出算式和题目，底部放答案与操作区。
- 避免依赖宽屏横排、悬停提示或精细拖拽；所有答题操作应可用一次轻触完成。
- 按钮和选项需有充足的触控面积与间距；页面适配常见手机安全区域，不让关键操作贴近屏幕边缘。
- 横屏不作为主要体验；若设备处于横屏，内容居中收窄并继续可玩，不强制提示旋转。
- 不出现横向滚动；数字、口诀和主要操作在常见手机竖屏视口内无需缩放即可看清。

## 2. 色彩

建议使用以下基础色，实际实现时可根据对比度微调：

| 用途 | 色彩 | 色值 |
|---|---|---|
| 页面背景 | 浅奶油色 | `#FFF8E8` |
| 主色/主要按钮 | 明亮蓝 | `#3978E8` |
| 辅助色/正确反馈 | 青绿 | `#27B99A` |
| 点缀/奖励 | 阳光黄 | `#FFC94A` |
| 温暖强调 | 珊瑚橙 | `#FF8068` |
| 正确状态 | 深青绿 | `#16866F` |
| 普通文字 | 深海军蓝 | `#24324A` |
| 次级文字 | 灰蓝 | `#65738A` |
| 卡片表面 | 白色 | `#FFFFFF` |

颜色用于辅助识别，不单独承担正确/错误含义；状态同时用图标、文字或形状表达。正文与背景保持充足对比。

## 3. 形状与组件

- 所有小游戏共用仓库根目录的 `assets/minigame-mark.svg` 作为入口标识：深蓝圆角底座上的迷你街机机台，配合小屏、十字键和双色按键，表达一个由多款小游戏组成的乐园。它不表达单一游戏主题，后续游戏直接复用，不为每个项目另做首页品牌图标。
- 卡片、按钮使用圆角矩形，圆角明显但不过度泡泡化。
- 主要按钮尺寸大、文字短，带轻微投影和按下反馈。
- 答案选项可做成颜色不同的圆角卡片，但文字和数字保持最高视觉优先级。
- 口诀课堂使用整洁的“口诀卡”：算式最大，积次之，口诀用醒目但短小的标签呈现。
- 图标使用简单的实心或描边风格，整套保持一致。

## 4. 插画与角色

- 可使用一位小小探险家/数学向导作为轻量陪伴角色，也可使用星星、纸飞机、云朵等游乐园元素。
- 角色只在首页、完成反馈和结果页出现；题目界面给数字留出空间。
- 表情友好、动作积极；答错时角色保持鼓励，不表现失望或嘲笑。
- 插画采用几何化、圆润的扁平风格，减少细节和复杂纹理。

## 5. 字体与数字

- 使用清晰的无衬线系统字体，优先选择常见中文系统字体，并提供通用 sans-serif 回退。
- 乘法算式中的数字采用较粗字重、清楚的等宽或对齐排布。
- `×`、`=` 与数字之间留出足够间距；避免使用易混淆的花体数字。
- 口诀文本应一眼可读，不使用手写体作为正文。
- 题目数字在手机上足够大，确保儿童单手持设备时也能看清。

## 6. 动效与声音

- 答对：卡片轻弹、星星飞入计分区或答案短暂发光，动画快速结束。
- 答错：正确答案柔和显现并停留片刻，便于读完算式与口诀。
- 页面切换使用轻微滑动或淡入，避免突然闪烁、强震动和长时间阻塞。
- 倒计时以平稳进度条为主；接近结束时可改变形状或增加文字提示，不只依靠颜色。
- 音效轻快且可关闭；不播放刺耳蜂鸣或失败音。

## 7. 教学模式与闯关模式的区分

- **口诀课堂**：更安静、更规整，使用大号教学卡和明确的“下一条”“再看一次”按钮；重点是看清算式、答案、口诀。
- **闯关模式**：颜色和动效稍活跃，显示倒计时、题目进度和收集奖励；避免加入讲解弹窗。
- 两个模式沿用同一套色彩、字体和卡片组件，通过布局与节奏区分用途。

## 8. 页面氛围

- 首页：像游乐园入口，两个模式入口一眼可辨；教学入口与闯关入口视觉权重相当。
- 题目页：背景简洁，算式和可操作答案集中在视线中心，外围装饰极少。
- 正确反馈：明快但短暂，马上回到答题节奏。
- 错误反馈：温和、清楚、可阅读；让正确答案成为视觉焦点，不使用红色大叉或扣分动画。
- 结果页：像完成一次探索，展示收集成果和待复习口诀，不做失败/淘汰氛围。

## 9. 避免事项

- 不用密集背景、细碎纹理或装饰性元素挤占题目空间。
- 不用只靠红绿颜色区分对错。
- 不用儿童化过强的字体、闪烁、持续粒子效果或过度音效。
- 不显示羞辱性文案、失败排名、生命耗尽或扣分惩罚。
- 不在普通闯关局中插入教学卡；教学内容只在用户主动进入口诀课堂时呈现。

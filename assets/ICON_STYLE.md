# 小游戏入口图标规范

## 用途

`minigame-mark.svg` 是整个小游戏集合的统一入口标识。它代表“游戏大厅”，不代表某一款具体游戏。所有新小游戏的首页、入口页和后续导航应复用同一图标。

## 核心概念

图标是一台简洁的迷你街机机柜：窄招牌灯、单一 CRT 屏幕和内收的控制台组成完整轮廓。它应在小尺寸下仍一眼读成街机。

## 视觉语言

- 外形：1:1 圆角方形，深蓝到靛蓝的渐变背景。
- 机柜：近白色主体，顶部略收窄，底部有短底座线。
- 屏幕：一整块深色 CRT 屏幕，显示抽象像素图案或点阵，不显示播放三角形。
- 控制区：屏幕下方有独立的浅色控制台，包含深色十字键和两个圆形按键。
- 点缀色：青绿用于招牌与屏幕像素，珊瑚橙与阳光黄只用于两个按键。

## 色彩

| 角色 | 色值 |
|---|---|
| 背景深蓝 | `#314B78` 至 `#202B48` |
| 机柜白 | `#F9FBFF` |
| 屏幕 | `#243654` |
| 青绿 | `#56D7C0` |
| 珊瑚橙 | `#FF866F` |
| 阳光黄 | `#FFC84E` |

## 必须遵守

- 保留完整机柜轮廓、单一屏幕、十字键和两个圆形按键。
- 采用扁平矢量形式，不依赖 emoji、照片、渐变高光或复杂纹理。
- 图标内部不放游戏标题、长文字、角色或具体游戏题材。
- 屏幕只用 3 至 5 个简洁像素块或点阵，避免变成视频播放器界面。

## 避免事项

- 不将机柜上半部分拆成大面积纯色块与独立播放界面。
- 不使用播放三角形、广告横幅、彩色积木或过多小装饰。
- 不为每款小游戏改造统一图标；游戏个性应由入口卡片和页面内容表达。
